- 574 项 Python 测试通过（包括本地管线、解析器、文档一致性、自动发布、证据篡改、R2 漂移、撤回、无身份元数据、代码 CI 授权和线上 canary）。compileall、refresh.sh 语法、diff 检查通过。
- 实际 6,558 条产品数据：256 分片、最大详情分片 203,305 字节、列表 10,828,580 字节、该产品共 259 个静态文件。保留原部署总文件数与单文件大小硬门禁。

- 修复全库上线时暴露的两个原局匹配缺口：先移除 PGN 注释变例再按规范化主线匹配；同一完整对局的中英文赛事头副本可合并，已知日期/身份事实冲突仍拒绝。缺 ID 与白方不在注册表时均可回退全库匹配。

## 自动运行与失败恢复

Analyze new archived brilliancies 成功后触发 Adjudicate and publish brilliancies。发布前要求成功 CI 对应同一 Scripts、工作流和策略正文。每份 R2 输入按条件 ETag 分段认证，生成前复核全部远端基线。包只含公开批准条目与哈希摘要。

已发布内容无变化时不提交，不形成 rebuild/analyze/publication 循环。基线漂移与并发 main 拒绝覆盖。artifact 保留 30 天，发布重试不重跑引擎；已提交但重建派发失败的重试会继续派发。撤回保留 tombstone，公开列表移除且 API 410。

统一重建、R2 认证和部署沿用原入口。部署 canary 新增妙手列表/各层详情/打包 PGN、正文哈希和旧快照拒绝验证。GitHub 发布、统一重建、部署及 canary 的生产回执全部通过后才可宣称已上线；本文件的本地验收本身不是生产回执。
