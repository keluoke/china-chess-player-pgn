# 国内身份高置信归组交付（2026-07-26）

## 结论

采纳方案对“评分死锁”和“用库内 FIDE 标注做真值”的判断，但没有采纳“唯一
中文名即可 high”。姓名基线 99.78% 精确率适合作为候选与回归基准，不足以作为
个体级身份事实；在 27,297 个实体规模上仍会系统性制造误并。

上线规则为 `identity-presentation-v4`：

1. 永久身份合并仍只允许 `player-identity-links.csv`。
2. 机器只生成可撤销的展示归组，不写 registry/manual/community。
3. 国内实体之间必须具备特色俱乐部加有序晋级，或特色俱乐部加未晋级后的有序
   同组延续；国内实体连接 FIDE 必须具备同赛事直接 FIDE 或特色俱乐部匹配。
4. 同赛事双记录、出生年冲突、年龄段倒退为硬否决；任一内部冲突使整个传递组件
   保持拆分。
5. 性别字段在公开组/女子组语境中不稳定。真值检验发现把它当硬冲突会误拆
   127 对同一 FIDE 棋手，因此只保留为自动归组软门禁。
6. 姓名、拼音、全库唯一、重复姓名和地区只参与候选排序，不触发自动展示归组。

## 自动真值门禁

`Scripts/validate_identity_clustering.py` 合并同一赛事的 players/standings 字段，
以已有 FIDE ID 为真值，每次统一快照重建都检查：

- 中文姓名基线精确率不低于 99.7%，召回率不低于 98%；
- 实际展示归组精确率不低于 99.5%，且至少有 100 条可判定真值边；
- 公开归组内不得出现硬冲突；
- 同一国内实体不得进入多个归组；
- 硬冲突误拆率必须低于 0.5%。

结果写入公开的聚合指标
`docs/data/registry/domestic/identity-quality.json`，不含姓名、俱乐部、赛事轨迹或
个体证据。任一门槛失败会中止整个快照，旧快照继续服务。

`reviewRequired` 与 `lowConfidence` 已拆成两个指标：机器展示归组可以是 high，
但在没有人工链接前仍可被提出异议，不能冒充永久身份决定。

## 前端

- 归组卡片统一显示“高置信归组”；
- 详情页说明归组依据通过成员级证据和硬冲突校验；
- FIDE 与无 FIDE 合并档案都提供“身份异议”入口，自动带入 group/member IDs；
- 异议继续走私密下载流程，导入后生成 `presentation-disputes.csv` tombstone，
  下一次投影强制拆分且不会自动复活。

## 明确未采用

- 唯一中文名直接 high；
- 姓名加省份自动合并；
- 无约束的同拼音或别名合并；
- 把机器展示归组写进人工身份链接表；
- 把性别不一致作为永久拆分事实；
- 在前端或公开指标中暴露俱乐部、个体证据链和信源信息。
