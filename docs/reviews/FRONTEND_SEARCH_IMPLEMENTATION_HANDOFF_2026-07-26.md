# 前端与搜索体验交付（2026-07-26）

## 已采用

1. 首页改为单一大号 hero 搜索框；输入框不再 disabled，并保留 GET 表单慢网兜底、
   桌面自动聚焦、移动端不自动弹键盘、combobox 与 live-region 语义。
2. 核心 bootstrap 单独作为必需数据；覆盖、bulk、参与度等辅助 manifest 失败时
   降级，不再摧毁整个搜索页。
3. 国内棋手搜索新增紧凑 routing index：中文名中段双字可路由到现有前缀
   shard，修复“逸凡”等查询漏召回，又不复制整份棋手行；单汉字仍按姓名首字
   桶截断展示，避免常见字触发数十个分片下载。
4. 搜索归一化剥离拼音声调；加入拼音首字母缩写，允许单汉字查询；同分排序改用
   对局数、赛事数、活跃状态等质量信号；7–8 位纯数字优先解释为 FIDE ID。
5. 排行榜更名为“棋手排行榜”，默认成年公开组；标准棋/快棋/超快棋、全部/女子、
   年龄组与出生年份均可筛选并写入 URL。各棋种独立构建，不再混合回退。
6. 出生年份筛选明确声明只覆盖有 FIDE 注册信息的棋手，并展示当前年份对应 U 组、
   样本较少提示和出生年待补数量。
7. 赛事目录、数据覆盖、通用贡献入口从公共导航收起并设为 `noindex,nofollow`；
   页面、脚本和构建仍保留。删除/匿名化请求在首页页脚和棋手详情持续可达。

## 明确未采用

- 不发布 Bradley–Terry 或名次映射“预估等级分”：当前尚无经过验证、可解释且稳定
  的估分契约，贸然上线会与 registry 权威等级分混淆。
- 不做编辑距离自动纠错与繁简自动合并：姓名场景的假阳性会造成身份误导；后续应先
  建只读建议回归集，不得把近似文本当作身份关系。
- 不为未成年人棋手批量生成静态 SEO 档案；在隐私、撤回与索引策略单独评审前，
  不把客户端搜索记录扩展成搜索引擎永久索引。
- 不做静默搜索遥测；零结果词继续只保存在浏览器本地。

## 验证重点

- Node 搜索核心回归覆盖带声调拼音、声母缩写、FIDE ID 和中段汉字路由。
- Python 回归覆盖多棋种/女子/出生年份独立排行、隐藏导航与隐私入口。
- 构建仍由 `build_release_snapshot.py` 统一生成，routing、排行榜和 v2 API 共用
  同一 `snapshotId`。
