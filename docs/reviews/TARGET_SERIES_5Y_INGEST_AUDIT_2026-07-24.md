## 二、完成的技术改造

### 2.1 两种 PGN 完整度

完整性报告新增并实际使用 `pgnIngestStatus`：

| 状态 | 含义 | 可否称全台完整 |
|---|---|---|
| `full-board-complete` | 全部已下、非轮空对局均有 PGN | 可以 |
| `source-published-complete` | 来源实际公开的直播棋谱全部入库，可能只覆盖前若干台 | 不可以 |
| `not-published` | 来源没有公开棋谱 | 不适用，不回抓 |
| `source-published-partial` | 来源公开棋谱存在少局或错配 | 不可以 |
| `source-published-missing` | 来源已公开但未完成归档/恢复 | 不可以 |

国内比赛不把“前十台”写死为固定分母；分母取每轮来源实际公开的棋谱。每局必须
与轮次、台次和双方 `playerNo` 唯一匹配。

### 2.2 Lichess Broadcast 交叉归档

新投影位于 `docs/data/bulk/lichess-events/`。匹配门禁为：

1. 只选亚少赛/世少赛标准慢棋主赛，排除 rapid、blitz、schools、junior、
   cup、training、eastern 等相邻赛事；
2. 赛事系列、年份/日期窗口、年龄/性别组必须相容；
3. 轮次及双方身份必须一致，FIDE ID 优先，规范化姓名只作回退；
4. 只有唯一 TNR/台次候选才接受，歧义局拒绝；
5. 保留广播容器总局数、匹配数和未匹配残差；
6. PGN 保留 Lichess Broadcast 名称、URL 和 CC BY-SA 4.0 许可/署名。

同时修复了两个发布基础问题：

- 合法 Zstandard skippable frame 不再被误判为损坏月度分片；
- `.pgn.zst` 月度原档只保留在本地/R2，不进入 Git manifest；`refresh.sh bulk`
  只发布 manifest、youth 投影和 `lichess-events` 投影。

## 六、中文名结论

姓名与等级分必须以 registry 为权威，赛事记录不能反向覆盖主档。

| 系列 | 检查范围 | 可得到规范中文名 | 结论 |
|---|---:|---:|---|
| 李成智杯 | 3,839 个名单行 | 3,837 | 仅 2 个明确身份缺口 |
| 世少赛 | 92 个 CHN 名单行 | 77 | 15 个需身份审核 |
| 亚少赛 | 424 个 CHN 名单行 | 288 | 136 个需身份审核，主要来自 2026 新棋手 |

棋协大师赛历史数据仍混有中文名尾逗号、地区后缀和纯拼音来源名。它们可以作为
赛事原始显示名保留，但不能直接成为权威 `chineseName`；应由 FIDE ID 对 registry
映射，缺 ID 或 registry 无中文名的记录进入 identity workbench。此次未批量猜名，
避免重演身份错标。
