# 赛事目录、组别归并与查谱优先实施记录

评估基线见 `REVIEW_2026-09-15_EVENT_DISCOVERY_AND_PGN_FIRST.md`。本次只调整独立代码工作区，沿用已验证的广播原片；不回抓 Chess-Results/FIDE，不修改采集工作区的 outbox。

## 已实现

- 29 类历史系列中文名称与别名规则置于 `data/community/event-series.json`。同系列后续年份继承名称，人工审核的名称优先；不确定的赛事保留原名。
- 父级赛事集中展示届次/站点，组别按项目、年龄、级别和性别排序。已审核 canonical 关系可连接缺日期的组别；未审核广播片段须有相容日期。旧 TNR 路由保留，排名和逐轮对阵不跨组汇总。
- 唯一棋谱事实保留全部来源观察，修复 `EventDate=????.??.??` 阻断有效 Date/UTCDate 的问题。赛事可查看局数按独立指纹和非空合法主线计算，不使用棋手关联次数。
- 独立有效 PGN 即使没有赛果页或 registry/FIDE ID 关联也能查阅；partial 结构化赛事和测试赛事仍隔离。新赛事派生包禁止反向进入事实输入。
- 目录默认有谱赛事，支持全部赛事、暂无棋谱及日期/系列筛选。父页与组别页有谱自动打开棋盘，包内可按双方姓名、年份、组别、轮次、结果和 ECO 文本筛选，空结果明确显示。
- PGN 包临时生成后通过既有内容寻址 R2、完整 inventory、新对象正文回读、轮换抽验和快照回执门禁发布，不把新派生正文放入 Git。部署复核同一认证回执，旧数字 TNR PGN 接口保持兼容。
- 每月 5 日的广播维护扩展到李成智杯与棋协大师赛。新增 `replay_only=true` 仅回读现有 R2 月片，缺失或哈希冲突即失败，不回退来源下载。维护铁律、运行手册和 collector runtime 白名单同步更新。
