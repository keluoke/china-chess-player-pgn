# Bulk PGN Attribution

`docs/data/bulk/lichess-broadcast/` mirrors the official Lichess broadcast PGN archive.

- Source: https://database.lichess.org/
- Broadcast calendar: https://lichess.org/broadcast
- License: Creative Commons Attribution-ShareAlike 4.0
- License URL: https://creativecommons.org/licenses/by-sa/4.0/

This repository stores the original monthly `.pgn.zst` shards and derived U8-U18 Chinese youth PGN/index packs generated from the mirrored shards. Derived files retain the same source attribution and license.
